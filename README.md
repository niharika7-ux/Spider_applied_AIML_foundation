# Python Fundamentals – Practice Work

## About this project
This repository contains small Python programs that I used to practise the basics of programming. Each file focuses on one topic and uses simple examples so the concepts are easier to understand and test.

## What I practised
- Variables and common data types
- Decisions using `if`, `elif`, and `else`
- Lists, tuples, sets, and dictionaries
- `for` and `while` loops
- Functions, parameters, and return values
- Reading and writing a text file
- Classes, objects, and methods
- A small marks-summary program combining a few concepts

## Folder contents
| File | Purpose |
| --- | --- |
| `variables_datatypes.py` | Stores sample information and checks its data types |
| `conditions.py` | Uses marks to decide a result and grade |
| `data_structures.py` | Demonstrates common Python collections |
| `loops.py` | Prints number sequences and calculates totals |
| `functions.py` | Contains reusable functions for calculations |
| `file_handling.py` | Writes and reads a small text file |
| `oops.py` | Demonstrates a class and its objects |
| `marks_summary.py` | Extra practice program that calculates a student's average |

## Requirements
- Python 3.10 or newer is recommended.
- No third-party packages are needed.

## How to run
1. Download or extract this folder.
2. Open the folder in VS Code or a terminal.
3. Run any file, for example:

   ```bash
   python conditions.py
   ```

4. For the file-handling example, the program creates `practice_notes.txt` in the current working directory.

## What I learned
Working through these examples helped me practise how Python stores information, makes decisions, repeats instructions, and groups code into functions and classes. The examples can be changed and run again with different values.
